This project is cricket dream 11 fanatasy team predictor.
git hub: https://github.com/Preethibalamurugan23/Fanatasy-Team-Predictor.git

How to start the application?
Please run docker-compose build and docker-compose up.
All the services will start, the application can be found at localhost:3001/
You can find the prometheus at localhost:9090/, FastAPI UI at localhost:8000/docs and the metrics of the app at localhost:8000/metrics. The model is hosted at localhost:5000/
Additional information can be found in the documentations.
